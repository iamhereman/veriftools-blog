## 1. Getting Started: Accessing the Restored Platform

Getting started on veriftools.live is designed to be streamlined, intuitive, and immediate. Users do not need complex installation routines or proprietary browser extensions. The platform operates as a modern progressive web application accessible through any standards-compliant desktop or mobile browser.

## 2. The 3-Step Document Synthesis Workflow

* Step 1: Choose Your Template: Browse the catalog categorized by jurisdiction (USA, UK, EU, Canada, Australia, etc.) and document type (Passports, National ID Cards, Driver's Licenses, Utility Bills, Bank Statements).
* Step 2: Customize Visual Parameters: Input the required personal details, issuance dates, document numbers, and residential address fields. Live interactive previews reflect all updates in real time.
* Step 3: Export in High Resolution: Once reviewed, select your export format (PDF, PNG, or JPG) and trigger the generation pipeline to download crisp, vector-accurate files instantly.

## 3. Common Troubleshooting Scenarios

| Issue Encountered | Likely Cause | Immediate Solution |
| :--- | :--- | :--- |
| Canvas Preview Not Updating | Stale browser cache or script blocker | Hard refresh (Ctrl+F5) and ensure JavaScript is enabled |
| Blurred Export on High-DPI Screens | Selecting standard web preview resolution | Select the '300 DPI Vector Export' option prior to download |
| Barcode Fails Scanner Validation | Truncated input string in demographic fields | Ensure all mandatory AAMVA fields have complete valid values |
| Old Bookmarked Links Failing | Pointing to retired veriftools.net or .com | Update bookmarks to point to https://veriftools.live |
